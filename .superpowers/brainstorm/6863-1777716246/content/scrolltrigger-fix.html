Fix: ScrollTrigger Animations

Fix the broken layout caused by GSAP ScrollTrigger start positions

The Problem

Current Issues

  • Hero section invisible on load: start: 'top 80%' means hero never triggers (it's at top of page)
  • Content flashes: Elements start at opacity 0 and never animate in if already visible
  • Stat counters broken: Counters start at 0 but never trigger if already in view
  • Reveal sections inconsistent: Some sections never become visible

The Fix

Updated GSAP Configuration
// Hero section - no scroll trigger, always visible
// Remove ScrollTrigger for the first section
gsap.fromTo(heroElements,
  { opacity: 0, y: 40 },
  { opacity: 1, y: 0, duration: 1.2, ease: 'power3.out' }
  // NO ScrollTrigger - plays immediately
)

// Story panels - trigger when they enter viewport
sections.forEach((section) => {
  gsap.fromTo(section,
    { opacity: 0, y: 60 },
    {
      opacity: 1,
      y: 0,
      duration: 0.8,
      ease: 'power2.out',
      scrollTrigger: {
        trigger: section,
        start: 'top 85%',  // When top of section hits 85% of viewport
        toggleActions: 'play none none reverse', // Play once, reverse on scroll up
      },
    }
  )
})

// Stat counters - use immediate callback if already visible
counters.forEach((el) => {
  const rect = el.getBoundingClientRect()
  const isVisible = rect.top < window.innerHeight

  if (isVisible) {
    // Animate immediately
    animateCounter(el)
  } else {
    // Use ScrollTrigger
    ScrollTrigger.create({
      trigger: el,
      start: 'top 90%',
      onEnter: () => animateCounter(el),
    })
  }
})

Changes Summary

Hero Section

Animate immediately on page load. No ScrollTrigger. 1.2s duration with power3 easing for cinematic feel.

Story Panels

Use toggleActions: 'play none none reverse' so they re-animate if user scrolls up. Start at 85% viewport.

Stat Counters

Check visibility on load. Animate immediately if visible, otherwise use ScrollTrigger with 90% threshold.

The Ways Cards

Stagger animation with 0.1s delay between cards. Use stagger: 0.1 in GSAP config.

Viewport Safety

Add a safety check to ensure all content becomes visible eventually:

// Fallback: If ScrollTrigger fails, show content after 2s
setTimeout(() => {
  document.querySelectorAll('.reveal-section').forEach(el => {
    if (el.style.opacity === '0') {
      el.style.opacity = '1'
      el.style.transform = 'none'
    }
  })
}, 2000)
