# Pantheon 0G Skill

OpenClaw skill modules for Pantheon: 0G Compute inference, 0G Storage memory, and AI battle mechanics.

## Compute modes

- `ZeroGComputeSkill` uses the direct 0G compute flow for verifiable battle computations.
- `ZeroGRouterSkill` uses the documented Router API for server-side inference.

Set `OG_COMPUTE_API_KEY` and `OG_COMPUTE_ROUTER_URL` to use the Router skill.
